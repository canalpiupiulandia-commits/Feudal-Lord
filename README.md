# 👑 Feudal Lord

> Simulador político e medieval feudal completo — estilo Paradox/Victoria 3

## 🎮 Como Jogar

Abra `index.html` no navegador. Nenhuma instalação necessária.

## ⚔️ Sistemas Implementados

### 🏰 Governo & Política
- **Você é o Rei** — tome decisões que afetam todo o reino
- **Conselho Real** (5 conselheiros): Chanceler, Marechal, Tesoureiro, Espião-Mor, Bispo
- **Sistema de Leis** (8 categorias): Fiscal, Trabalho, Terra, Religião, Sucessão, Comércio, Educação, Militar
- **Estabilidade & Legitimidade** — afetam tudo no reino

### 👥 População & Sociedade
- **6 Grupos Sociais**: Camponeses, Artesãos, Mercadores, Nobreza, Clero, Intelectuais
- **Dinâmica econômica**: Mais pobres = mais mão de obra; Mais ricos = mais empregos
- **Censo demográfico**: Homens/Mulheres × Faixas etárias (0-14, 15-29, 30-59, 60+)
- **Taxa de natalidade** afetada por: alimentação, saúde, prosperidade
- **Mobilidade social**: camponeses podem tornar-se artesãos

### 💰 Economia
- **PIB em tempo real** calculado com produção + comércio privado
- **Sistema de impostos** (4 regimes): do mínimo ao esmagador
- **Negócios privados**: mercadores e artesãos geram empregos e renda
- **7 Recursos**: Ouro, Alimentos, Madeira, Pedra, Ferro, Tecido, Educação
- **Sistema de dívida** com juros anuais

### 🏗️ Construções (13 tipos)
| Categoria | Construções |
|---|---|
| 🌾 Agrícola | Fazenda, Celeiro, Pasto |
| ⚙️ Indústria | Madeireira, Mina, Ferraria, Moinho, Curtume |
| 🏛️ Serviços | Mercado, Escola, Igreja, Hospital, Quartel |

### 🔬 Pesquisa (22 tecnologias)
- Agricultura, Indústria, Governança, Medicina, Comércio

### ⚕️ Saúde
- Índice de saúde, pragas, hospitais, doenças rastreadas

### 🗡️ Intrigas Políticas
- 5 tipos de conspiração, rede de espiões, resposta real

### 📣 Eventos
- 12+ eventos aleatórios com escolhas impactantes

### 💾 Save System
- Salvar/carregar via localStorage

### ⏱️ Tempo Real
- Pausa/Play, velocidades 1x/2x/4x

## 🎯 Dicas
1. Comece com Fazendas
2. Construa um Mercado cedo
3. Pesquise Burocracia
4. Mantenha Estabilidade acima de 50
5. Invista em Hospitais

## 🛠️ Tecnologias
- HTML5 / CSS3 / JavaScript Vanilla
- Sem dependências externas
- Save via localStorage
